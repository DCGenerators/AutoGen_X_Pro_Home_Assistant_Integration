# AutoGen X Pro

Connect an AutoGen X Pro controller to Home Assistant with automatic local discovery and UI-based setup.

Monitor controller state and electrical readings, and start or stop the generator
through the controller's existing safety/state-machine path. The permanent
AutoGen device ID is retained for support and identity.

The matching Home Assistant-enabled AutoGen X Pro firmware is required. This
pre-release build is for test controllers only until hardware validation is
complete.
